# GdprDpia

Filament plugin for laravel-gdpr-dpia: data protection impact assessments (Art. 35) in your panel, with risks before and after measures, DPO advice, approval, prior consultation flag and the activities still missing one.

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/filament-gdpr-dpia
```
